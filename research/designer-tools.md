# Teaching Threads: The Physical Tools of a Fashion Designer

_October 2026. Research for the website's 3D and interaction ideas. Arun suggested modelling real studio tools (fabric shears, seam rippers, thread snips) and using them on the site._

The tools are grouped by the stage of making where they're used. Each one has a short note on what it does and why it's interesting visually.

---

## 1. Measuring

| Tool | What it does | Visual notes |
|---|---|---|
| **Measuring tape** (inch tape, *fita*) | Takes body measurements and measures curves. Indian tailors wear it draped round the neck. | The most recognisable tailor symbol. Flexible, so it can unroll, coil and wrap. Has numbers printed on it. |
| **Naap book** | The tailor's measurement ledger: one page per client. | Ledger lines, handwriting, numbers. |
| **Seam gauge / sewing gauge** | A small 6" metal ruler with a sliding marker for hems and seam allowances. | Small, metallic, with a sliding part. |
| **Hem gauge** | A curved metal template for pressing hems evenly. | |
| **Clear grid ruler** (2" × 18") | Adds seam allowances and draws parallel lines. | Transparent with a grid. |
| **Metre stick / yardstick** | Measures fabric lengths and draws long straight lines. Indian tailors use a steel scale. | |

## 2. Pattern making and drafting

| Tool | What it does | Visual notes |
|---|---|---|
| **French curve** | Shapes armholes and necklines. | A beautiful abstract shape that works well as a 3D object or graphic. |
| **Hip curve** | Draws long gentle curves for hips, side seams and hems. | Long, elegant and slightly sabre-like. |
| **L-square** | Draws right angles and straight edges in one go. | A strong geometric shape. |
| **Pattern notcher** | Punches small notches in the pattern edge to mark seam allowances, centre lines and ease points. | Like a ticket punch. Makes a satisfying "clip". |
| **Pattern drill / awl** | Punches holes for dart points and pocket positions. | |
| **Tracing wheel** (pointed or blunt) | Copies lines through paper, or onto muslin using carbon paper. | Leaves a **dotted line** behind it, a ready-made animation idea. |
| **Pattern hooks** | Hang finished pattern sets on rods. | Big metal hooks with brown paper pieces on them make an iconic studio sight. |
| **Pattern weights** | Hold paper and fabric flat without pins. | |
| **Pattern paper / dot-and-cross paper / manila card** | Drafting surface; card is used for permanent blocks. | |
| **Muslin / calico** | Cheap fabric for the toile, the test garment. | |

## 3. Marking

| Tool | What it does | Visual notes |
|---|---|---|
| **Tailor's chalk** (clay triangle, *khadiya*) | Marks lines on fabric before cutting. | Leaves a soft, dusty line that works well for annotations. |
| **Chalk wheel / chalk pen** | Draws a fine, precise chalk line. | |
| **Tailor's wax** | Marks wool and dark fabric. The mark melts away when ironed. | |
| **Dressmaker's carbon paper** | Used with the tracing wheel. | |
| **Disappearing / water-erasable pens** | Temporary marks. | |
| **Thread tracing / tailor's tacks** | Marking with loose basting stitches, used in couture. | |

## 4. Cutting

| Tool | What it does | Visual notes |
|---|---|---|
| **Fabric shears / dressmaker's shears** (*kainchi*) | 8–12", bent handle so the blade stays flat on the table while cutting. Never used on paper. | **The hero object.** Heavy, forged steel and instantly understood. Indian tailors' kainchi are often big, all-metal and black. |
| **Tailor's shears** | Heavier and longer, for wool and multiple layers. | |
| **Pinking shears** | Zigzag blades that finish raw edges so they don't fray. | The zigzag edge can become a graphic divider. |
| **Paper scissors** | Kept separate because paper blunts fabric shears. | |
| **Thread snips / nippers** | Spring-loaded clippers for trimming threads at the machine. | Small and quick: a "snip". |
| **Embroidery scissors** (stork scissors) | Small, sharp, for fine work. The classic design is shaped like a stork. | Ornamental and very photogenic. |
| **Duckbill / appliqué scissors** | One paddle-shaped blade, for trimming close without cutting the base fabric. | |
| **Rotary cutter + self-healing mat** | Straight, fast cutting. | The mat has a grid. |
| **Buttonhole cutter / chisel** | Opens buttonholes cleanly. | |
| **Seam ripper** (*unpicker*) | Unpicks stitches: a fork with a sharp hook and a small red ball. | Every student's most-used tool. Linked to mistakes and "do it again", which gives it a human story. |

## 5. Hand sewing and construction

| Tool | What it does | Visual notes |
|---|---|---|
| **Pins** (glass-head, silk, dressmaker's) | Hold fabric pieces together. | |
| **Pin cushion** (tomato, wrist or magnetic) | Holds pins. | The tomato with a strawberry is iconic. A wrist cushion is worn while fitting. |
| **Hand needles** (sharps, betweens, beading) | Hand stitching. | |
| **Thimble** (metal, leather; Indian tailors also use ring-style) | Protects the finger when pushing a needle. | Small, dimpled and cute as a 3D object. |
| **Needle threader** | Small wire loop. | |
| **Bodkin** | Threads elastic and cord through casings. | |
| **Loop turner** | Turns narrow tubes such as rouleau loops and lehenga dori right side out. | |
| **Point turner** | Pushes out the corners of collars and cuffs. | |
| **Awl / stiletto** | Makes eyelets and guides fabric under the presser foot. | |
| **Beeswax** | Strengthens thread for hand sewing. | |
| **Thread spools and cones** | The supply of thread. | Easy to show in 3D. Can unspool into a line. |
| **Bobbins and bobbin case** | Supply the lower thread in the machine. | |

## 6. Machines

| Tool | What it does | Visual notes |
|---|---|---|
| **Sewing machine** (domestic, industrial lockstitch, Usha/Singer treadle in India) | The main construction tool. | The black Singer/Usha with gold decals carries strong Indian nostalgia. |
| **Overlocker / serger** | Trims and finishes seam edges in one pass. | |
| **Coverstitch machine** | Hems knits. | |
| **Buttonhole and button-attaching machines** | Production finishing. | |

## 7. Fitting

| Tool | What it does | Visual notes |
|---|---|---|
| **Dress form / mannequin** (adjustable or padded) | Drape, fit and display garments. | **The other hero.** Iconic silhouette, and it can "wear" each stage: toile, then finished piece. |
| **Draping tape** (style tape) | Marks style lines on the dress form before drafting. | Black lines on a cream form, a perfect black-on-off-white graphic. |
| **Hanger and garment rail** | | |

## 8. Pressing

| Tool | What it does | Visual notes |
|---|---|---|
| **Steam iron / industrial iron** (heavy *press* in Indian shops) | Pressing, which is different from ironing: the iron is lifted and lowered rather than slid. | |
| **Tailor's ham** | A curved cushion, wool on one side and cotton on the other, for pressing darts and curves. | An unusual object most people don't recognise, so it can be a talking point. |
| **Seam roll** | Presses seams open inside sleeves. | |
| **Sleeve board** | A small ironing board for sleeves. | |
| **Clapper / point presser** | A wooden block that sets crisp seams, plus a pointed end for collar corners. | |
| **Needle board** | Presses velvet without crushing the pile. | |
| **Press cloth** | Protects fabric from shine. | |

## 9. Indian embroidery (the zardozi and aari studio)

This is the part that makes Teaching Threads different from a generic fashion school. These tools are specific to Indian bridal couture.

| Tool / material | What it is | Visual notes |
|---|---|---|
| **Adda** (*karchob*) | A large wooden frame that holds the fabric tight. Several karigars sit around it and work together. | Very cinematic: a whole lehenga panel stretched flat, with hands working around it. |
| **Aari** | A hooked needle like a fine crochet hook in a wooden handle. Makes a fast chain stitch. | Elegant, unusual tool. |
| **Khaka / pricked paper** | The design is pricked onto paper, then transferred to fabric with a kerosene-and-powder (neel or chalk) solution. | Rows of tiny holes, which echoes the dot-matrix/ASCII idea. |
| **Kasab** | Thread wrapped in metallic strip. | |
| **Dabka / nakshi** | Coiled metal wire, like a tiny spring. | |
| **Salma** | Coiled wire that is shinier than dabka. | |
| **Tilla** | Flat metallic thread, used in Kashmir and elsewhere. | |
| **Sitara, moti, cut-dana** | Sequins, pearls and cut beads. | Dots on a grid: this is the real-world version of the X ASCII effect. |

## Shortlist for 3D or animated use

The objects with the strongest, most recognisable silhouettes:

1. **Fabric shears** (kainchi): the hero. They can open and close to "snip" between sections.
2. **Measuring tape**: unrolls, coils, counts.
3. **Dress form**: wears each stage of a garment.
4. **Seam ripper**: has a story, since every student uses it.
5. **French curve / hip curve**: abstract, sculptural, designer-y.
6. **Thread spool**: unspools into a line that runs through the page.
7. **Thimble, pin cushion with pins**: small, tactile, playful.
8. **Aari hook and adda**: the Indian, couture-specific tools no other academy site would show.

**Suggestion:** scan or photograph **Shruti's own tools**, worn and real, rather than using stock CG models. Her actual kainchi, tape and aari carry twenty years of use, which is the brand story.
